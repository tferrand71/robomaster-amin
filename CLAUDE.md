## Quality Guardrails

### SEO Requirements
- Every page must have a unique `title` (50-60 characters)
- Every page must have a `description` (120-160 characters)
- Use semantic HTML: one `<h1>` per page, proper heading hierarchy
- All images must have descriptive `alt` text
- URLs should be clean, lowercase, hyphenated

### Accessibility Requirements
- All interactive elements must be keyboard accessible
- Color contrast must meet WCAG AA (4.5:1 for text)
- Form inputs must have associated labels
- Use ARIA attributes appropriately
- Provide skip navigation links

### Performance Requirements
- Optimize images: use WebP/AVIF, appropriate sizes
- Lazy load images below the fold
- Minimize JavaScript bundle size
- Use appropriate caching headers
- Avoid render-blocking resources

### Security Requirements
- Never output unescaped user input
- Use HTTPS for all external resources
- Validate and sanitize all form inputs
- Set appropriate Content-Security-Policy headers
- Keep dependencies updated

## Content Guidelines

When creating or editing content:

1. **Front Matter**: Always include required fields (title, date, description)
2. **Formatting**: Use consistent markdown style, one sentence per line for diffs
3. **Links**: Use relative links for internal content, verify external links
4. **Images**: Place in appropriate asset directory, use descriptive filenames
5. **Drafts**: Mark work-in-progress with draft status

## File Structure

Follow the framework's conventions for organizing files:
- Keep content in the designated content directory
- Use clear, descriptive filenames (lowercase, hyphenated)
- Group related content in subdirectories
- Keep assets close to the content that uses them
